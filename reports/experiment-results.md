# A/B 테스트 자체 사용 결과 보고서

## 1. 테스트 개요

이번 테스트는 계산기 서비스의 A 그룹과 B 그룹의 기능 및 사용 편의성을 비교하기 위해 진행하였다.

- 테스트 방식: 1인 자체 반복 테스트
- 테스트 횟수: 총 8회
- A 그룹: 4회
- B 그룹: 4회
- 테스트 대상: 계산, 오류 안내, 결과 복사, 계산 기록
- 데이터 유형: 자체 테스트 결과

※ 본 결과는 실제 사용자 8명의 평가가 아니라 한 명이 반복하여 진행한 자체 테스트 결과이다. 실제 사용자 10명 이상의 피드백 및 2주간의 A/B 테스트 결과와는 구분한다.

## 2. A 그룹 테스트 결과

A 그룹은 기존 계산기 기능을 기준으로 테스트하였다.

| 테스트 항목 | 결과 |
|---|---|
| 덧셈 125 + 375 | 500, 성공 |
| 빈 입력값 검증 | 브라우저 오류 안내창 표시 |
| 뺄셈 15000 - 3500 | 11500, 성공 |
| 곱셈 12500 × 8 | 100000, 성공 |
| 나눗셈 48 ÷ 6 | 8, 성공 |
| 나눗셈 10 ÷ 3 | 3.3333333333333335 |
| 나눗셈 1 ÷ 3 | 0.3333333333333333 |
| 계산 기록 | 정상 표시 |

### A 그룹 사용자 의견

- 오류 안내창은 이해하기 쉬웠다.
- 큰 숫자로 갈수록 결과를 읽기 불편했다.
- 천 단위 쉼표가 표시되면 좋겠다는 의견이 있었다.
- 소수점이 지나치게 길게 표시되는 점이 아쉬웠다.

## 3. B 그룹 테스트 결과

B 그룹은 사이트 내부 오류 안내와 결과 복사 기능이 추가된 버전으로 테스트하였다.

| 테스트 항목 | 결과 |
|---|---|
| 덧셈 125 + 375 | 500, 성공 |
| 빈 입력값 검증 | 사이트 내부 오류 메시지 표시 |
| 결과 복사 | 복사 완료 메시지 표시 |
| 곱셈 12500 × 8 | 100000, 성공 |
| 나눗셈 10 ÷ 3 | 3.3333333333333335 |
| 나눗셈 1 ÷ 3 | 0.3333333333333333 |
| 계산 기록 | 정상 표시 |

### B 그룹 사용자 의견

- 사이트 내부 오류 안내가 가장 유용했다.
- 전체적인 사용 방법을 이해하기 쉬웠다.
- 큰 숫자에 천 단위 쉼표가 필요하다.
- 소수점 자릿수를 제한하면 좋겠다.
- 결과 복사 후 어디에 붙여넣는지, 다시 복사하려면 어떻게 해야 하는지 안내가 있으면 좋겠다.

## 4. A/B 그룹 비교

| 비교 항목 | A 그룹 | B 그룹 |
|---|---|---|
| 계산 기능 | 정상 작동 | 정상 작동 |
| 오류 안내 | 브라우저 팝업 | 사이트 내부 메시지 |
| 결과 복사 | 버튼 없음 | 복사 기능 제공 |
| 계산 기록 | 정상 작동 | 정상 작동 |
| 사용 편의성 | 오류 안내창은 이해하기 쉬움 | 사이트 내부 안내가 더 유용하다고 평가 |

## 5. 발견한 개선 사항

자체 테스트를 통해 다음과 같은 개선점을 발견하였다.

1. 큰 숫자에 천 단위 쉼표를 표시하여 가독성을 높인다.
2. 소수점 자릿수를 적절히 제한하여 결과를 보기 쉽게 만든다.
3. 결과 복사 후 붙여넣기 방법과 재복사 방법을 안내한다.

## 6. 테스트의 한계

이번 테스트는 한 명이 A 그룹과 B 그룹을 각각 네 차례 이용한 자체 테스트이다.

따라서 여러 사용자의 다양한 의견을 반영했다고 보기 어렵고, 통계적으로 유의미한 A/B 테스트 결과라고 할 수 없다.

또한 실제 2주간의 사용자 데이터를 수집한 것은 아니다.

추후 실제 참가자 10명 이상을 모집하여 사용자 피드백을 수집하고, 2주간 A/B 테스트를 진행하여 결과를 추가로 비교할 계획이다.

## 7. 결론

이번 자체 테스트에서는 B 그룹의 사이트 내부 오류 안내와 결과 복사 기능이 정상적으로 작동하는 것을 확인하였다.

특히 사이트 내부 오류 안내 기능이 사용하기 편리하다는 평가를 받았다.

다만 두 그룹 모두 큰 숫자와 소수점 표시에서 개선이 필요하다는 점이 확인되었다.

향후 실제 사용자 피드백과 2주간의 실험 데이터를 수집한 후 최종적인 Pivot 또는 Persevere 결정을 내릴 예정이다.

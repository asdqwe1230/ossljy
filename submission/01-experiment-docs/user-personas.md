# 계산기 서비스 사용자 페르소나 10명

본 문서는 LLM을 활용하여 생성한 가상 사용자 10명의 페르소나를 정리한 자료이다. 각 사용자는 서로 다른 연령, 직업, 컴퓨터 활용 능력 및 계산기 사용 목적을 갖도록 설정하였다.

## U01. 대학생
- 직업: 대학생
- 성향: 과제 수행을 위해 계산기를 자주 사용함
- 사용 목적: 수학 과제와 일반적인 사칙연산
- 기대사항: 계산 결과를 빠르고 정확하게 확인하고 싶음
- 불편사항: 계산 결과를 다시 확인하기 어려움

## U02. 직장인
- 직업: 사무직 직장인
- 성향: 빠르고 효율적인 작업을 선호함
- 사용 목적: 업무 중 금액 및 수치 계산
- 기대사항: 최소한의 조작으로 계산 완료
- 불편사항: 입력 과정이 복잡하면 불편함을 느낌

## U03. 회계 담당자
- 직업: 회계 담당자
- 성향: 정확성과 검증을 중요하게 생각함
- 사용 목적: 비용과 금액 계산
- 기대사항: 계산 결과를 쉽게 확인하고 복사하고 싶음
- 불편사항: 계산 결과를 다른 업무에 옮기기 불편함

## U04. 수학 초보자
- 직업: 고등학생
- 성향: 계산기 사용에 익숙하지 않음
- 사용 목적: 기본적인 사칙연산 학습
- 기대사항: 쉬운 화면과 명확한 안내
- 불편사항: 잘못된 입력에 대한 안내가 부족하면 혼란스러움

## U05. 공학 전공자
- 직업: 공학 전공 대학생
- 성향: 다양한 계산 기능을 활용함
- 사용 목적: 일반 계산 및 제곱 계산
- 기대사항: 공학용 계산 기능과 계산 기록
- 불편사항: 기능이 제한적이면 불편함

## U06. 고령 사용자
- 직업: 은퇴자
- 성향: 단순하고 직관적인 화면을 선호함
- 사용 목적: 생활비와 일상적인 수치 계산
- 기대사항: 큰 버튼과 읽기 쉬운 안내
- 불편사항: 작은 글씨와 복잡한 화면을 어려워함

## U07. 모바일 중심 사용자
- 직업: 대학생
- 성향: 스마트폰과 모바일 환경에 익숙함
- 사용 목적: 이동 중 간단한 계산
- 기대사항: 작은 화면에서도 편리한 입력
- 불편사항: 모바일 화면에서 버튼이 작으면 불편함

## U08. 기록 중시 사용자
- 직업: 프리랜서
- 성향: 이전 작업 결과를 확인하는 습관이 있음
- 사용 목적: 반복적인 계산 및 결과 비교
- 기대사항: 계산 기록을 쉽게 확인하고 싶음
- 불편사항: 이전 계산 결과가 사라지면 불편함

## U09. 빠른 작업 선호 사용자
- 직업: 매장 관리자
- 성향: 짧은 시간에 여러 계산을 수행함
- 사용 목적: 판매 금액 및 수량 계산
- 기대사항: 빠른 입력과 즉각적인 결과 표시
- 불편사항: 불필요한 단계가 많으면 불편함

## U10. 컴퓨터 초보 사용자
- 직업: 일반 사용자
- 성향: 웹 서비스 사용 경험이 많지 않음
- 사용 목적: 일상적인 사칙연산
- 기대사항: 명확한 버튼 이름과 오류 안내
- 불편사항: 잘못된 값을 입력했을 때 해결 방법을 알기 어려움

---

## 페르소나 생성 방법
- 생성 방식: LLM 기반 가상 사용자 생성
- 사용자 수: 10명
- 구성 기준: 직업, 사용 목적, 사용 습관, 디지털 활용 능력 및 요구사항
- 활용 목적: 계산기 서비스의 사용성 평가와 A/B 테스트 시나리오 작성

※ 본 자료는 실제 사용자 조사 결과가 아닌 LLM으로 생성한 가상 사용자 프로필이다.

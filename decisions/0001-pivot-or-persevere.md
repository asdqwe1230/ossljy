# ADR 0001: Pivot 또는 Persevere 결정 기록

## 1. 결정 개요

- 결정 날짜: 2026-11-26
- 프로젝트: 계산기 서비스 A/B 테스트
- 결정 상태: 잠정 결정
- 결정 유형: Persevere (현재 개발 방향 유지)

## 2. 결정 배경

계산기 서비스의 사용 편의성을 개선하기 위해 A 그룹과 B 그룹으로 나누어 자체 테스트를 진행하였다.

A 그룹은 기존 계산기 기능을 사용하고, B 그룹은 사이트 내부 오류 안내와 결과 복사 기능을 추가한 버전을 사용하였다.

자체 테스트는 한 명의 사용자가 각 그룹에서 4회씩, 총 8회 진행하였다.

## 3. 테스트 결과

### A 그룹

- 기본 사칙연산이 정상적으로 작동하였다.
- 입력값이 비어 있을 때 브라우저 오류 안내창이 나타났다.
- 계산 기록이 정상적으로 표시되었다.

### B 그룹

- 기본 사칙연산이 정상적으로 작동하였다.
- 입력값이 비어 있을 때 사이트 내부에 오류 메시지가 표시되었다.
- 결과 복사 기능이 정상적으로 작동하였다.
- 계산 기록이 정상적으로 표시되었다.

### 공통 개선 사항

두 그룹 모두 다음과 같은 개선점이 발견되었다.

1. 큰 숫자에 천 단위 쉼표가 필요하다.
2. 소수점 자릿수를 적절히 제한할 필요가 있다.

B 그룹에서는 추가로 다음 의견이 나왔다.

- 결과 복사 후 붙여넣기 방법과 재복사 방법을 안내하면 좋겠다.

## 4. 고려한 선택지

### 선택지 1: Pivot

현재 개발 방향을 변경하고 새로운 기능이나 사용자 경험을 중심으로 개발 방향을 다시 설정한다.

### 선택지 2: Persevere

현재 개발 방향을 유지하면서 사용자 피드백을 바탕으로 기존 기능을 개선한다.

## 5. 결정 사항

현재는 Persevere를 잠정적으로 선택한다.

자체 테스트에서 B 그룹의 사이트 내부 오류 안내와 결과 복사 기능이 정상적으로 작동했으며, 테스트 과정에서 현재 개발 방향을 완전히 변경해야 할 문제는 발견되지 않았다.

따라서 기존 방향을 유지하면서 숫자 표시와 복사 안내 기능을 개선하는 것이 적절하다고 판단하였다.

## 6. 후속 작업

1. 천 단위 쉼표 표시 기능 검토
2. 소수점 자릿수 제한 기능 검토
3. 결과 복사 후 사용 방법 안내 추가
4. 실제 사용자 10명 이상의 피드백 수집
5. 2주간 A/B 테스트 진행
6. 실제 실험 데이터를 바탕으로 최종 Pivot 또는 Persevere 결정

## 7. 결정의 한계

이번 결정은 한 명이 반복해서 진행한 자체 테스트 결과를 바탕으로 한 잠정 결정이다.

실제 사용자 10명 이상의 피드백과 2주간의 A/B 테스트 데이터가 아직 수집되지 않았으므로 통계적으로 유의미한 결론이라고 볼 수 없다.

추후 실제 실험 결과에 따라 현재 결정을 변경할 수 있다.

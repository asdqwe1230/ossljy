
# OSSLJY Calculator

간단한 계산 기능을 제공하는 npm 패키지입니다.

## Installation

npm install @asdqwe1230/ossljy-calculator

## Usage

const calculator = require('@asdqwe1230/ossljy-calculator');

console.log(calculator.add(10, 5));
console.log(calculator.subtract(10, 5));
console.log(calculator.multiply(10, 5));
console.log(calculator.divide(10, 5));

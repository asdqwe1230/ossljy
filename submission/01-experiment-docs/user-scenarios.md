# 계산기 서비스 사용자 시나리오

## 1. 목적
LLM으로 생성한 10명의 가상 사용자가 계산기 서비스를 이용하는 상황을 정의하고, 사용자 요구사항에 따라 서비스의 사용성을 평가한다.

## 2. 사용자별 시나리오

| ID | 사용자 | 사용 시나리오 | 기대 결과 |
|---|---|---|---|
| U01 | 대학생 | 과제 중 125 + 375 계산 | 정확한 결과 500 표시 |
| U02 | 직장인 | 업무 중 15000 - 3500 계산 | 빠른 결과 확인 |
| U03 | 회계 담당자 | 12500 × 8 계산 후 결과 복사 | 100000 표시 및 복사 |
| U04 | 수학 초보자 | 48 ÷ 6 계산 및 잘못된 입력 시도 | 결과 8과 명확한 오류 안내 |
| U05 | 공학 전공자 | 12의 제곱 계산 | 결과 144 표시 |
| U06 | 고령 사용자 | 2500 + 1500 계산 | 읽기 쉬운 결과 표시 |
| U07 | 모바일 사용자 | 작은 화면에서 30 × 4 계산 | 모바일에서도 정상 작동 |
| U08 | 기록 중시 사용자 | 100 + 200 계산 후 계산 기록 확인 | 결과 300과 기록 저장 |
| U09 | 매장 관리자 | 4500 × 12 계산 | 빠르게 결과 54000 표시 |
| U10 | 컴퓨터 초보자 | 숫자를 입력하지 않고 계산 버튼 클릭 | 오류 원인과 해결 방법 안내 |

## 3. 공통 테스트 절차

1. 계산기 웹 페이지에 접속한다.
2. 각 사용자에게 지정된 계산 작업을 수행하게 한다.
3. 계산 결과가 정확한지 확인한다.
4. 입력 과정과 화면 구성을 평가한다.
5. 사용 중 불편했던 점과 개선 의견을 기록한다.

## 4. A/B 테스트 시나리오

### A 그룹
- 기존 계산기 화면 사용
- 기본적인 계산 기능 제공
- 기본 입력 오류 알림 제공

### B 그룹
- 개선된 계산기 화면 사용
- 입력 오류를 화면에 명확하게 표시
- 계산 결과 복사 기능 제공

## 5. 평가 항목

- 계산 성공 여부
- 계산 완료 소요 시간
- 화면 사용 편의성
- 오류 안내의 이해도
- 전반적인 만족도

## 6. 평가 방법
각 페르소나가 동일한 계산 작업을 A 그룹과 B 그룹에서 수행한다고 가정하고, 사용성 차이를 비교한다.

※ 페르소나별 평가 결과는 LLM 시뮬레이션 결과이며 실제 사용자 실험 결과와 구분하여 관리한다.
